Privacy Policy – Datatin Uploader

Last updated: 14 October 2026

Datatin Uploader is a private tool used only by the owner of the YouTube channel "Datatin" to upload the channel's own videos. It uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service.

What data we access

Through the YouTube Data API the tool only uploads videos, their metadata (title, description, tags, privacy status) and thumbnails to the owner's channel, using the OAuth scope youtube.upload. It does not read, collect or store any other user data, viewer data, comments or analytics.

Storage

The tool stores only the OAuth refresh token of the channel owner, as a private setting of the cloud environment that runs it (accessible only to the owner), and the IDs of the videos it uploaded. No data from other users is ever processed. Nothing is shared with or sold to third parties.

Google

Google's Privacy Policy applies to data processed by Google: https://policies.google.com/privacy

Revoking access and deletion

The owner can revoke the tool's access at any time from https://myaccount.google.com/permissions; the stored token is then deleted from the environment within 7 days, together with any stored data.
